# InSTability supplementary code

[Clustering code](clustering/README.md) for the paper's 10 methods, 18 samples,
and 50 clustering runs per sample and method.

The instability method is maintained separately in
[molloy-lab/InSTability](https://github.com/molloy-lab/InSTability).

[Figure code and minimal plotting data](figures/README.md) reproduce Figures 2–4,
supplementary figures S1–S37, and Tables 3–9.

We provide code for figures and tables that showcase data; Figure 1 is a motivating example created in Adobe Illustrator, and Tables 1–2 use publicly available information, so their code is not included.
