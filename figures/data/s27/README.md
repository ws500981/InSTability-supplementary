S27 inputs contain the saved per-sample mean absolute differences for 10 methods,
18 samples, and 5–50 runs. Both nested and sampled modes are included.

For sampled mode, absolute differences from the same sample's 50-run spot scores
were averaged over spots, then over 25 replicates. Nested mode uses the first K
runs. The plot recomputes equal-weight sample means and SEM (sample SD / sqrt(18)).
No clustering or instability calculation is needed to plot these tables.

`sources.json` records the original analysis-relative CSV paths and checksums.
